# SPEEDPDFEDIT
Free online PDF editor. Edit, sign, OCR, compress, protect, split and merge PDFs in the browser. No login, no payments, files never leave the device.

## Run locally
    npm install
    npm run dev        # opens http://localhost:5173

## Deploy
Push to GitHub, then import the repo in Vercel (Framework: Vite, Build: `npm run build`, Output: `dist`).
